## Превышение индикатора расчетного размера городских домохозяйств над региональными нормативами на основе ведомственных данных жилого фонда г. Твери

Статистико-географическое исследование, посвященное оценке реального демографического потенциала жилой застройки города Твери в межпереписной период, сопровождавшийся полной ликвидацией инфраструктуры городского электрического транспорта (ГЭТ).

## Объект исследования

Объектом анализа выступает: многоквартирный жилой фонд (МКД) в административно-территориальных границах города Твери.

## Цель

Составить часть материала для геодемографического и инфраструктурного анализа для курсовой работы 2 курса "Ликвидация систем городского электрического транспорта в Твери и пространственная доступность инфраструктуры". Доказать или опровергнуть предположение о наличии критических лакун и дисбаланса в ведомственном учете жилых площадей, формирующих скрытые зоны пассажирского спроса.

## Гипотеза

Официальный ведомственный учет многоквартирного жилого фонда содержит системные пустоты и недоучитывает физический объем жилой площади города, из-за чего локальный расчетный размер домохозяйств математически завышается относительно реальных демографических трендов, маскируя очаги транспортной нагрузки.

## Уточнения

- При подготовке датасета использовалась официальная открытая выгрузка реестра домов Тверской области с государственного портала «Реформа ЖКХ» объемом около 90 МБ.
- В качестве базового статистического ориентира использовались таблицы научного издания [Демоскоп Weekly](http://demoscope.ru) (средний размер частных домохозяйств в городских населенных пунктах региона равен 2.4 человека).
- Официальные демографические вехи численности населения г. Твери (403 606 жителей в 2010 г. и 416 219 жителей в 2021 г.) взяты из официальных бюллетеней и результатов Всероссийской переписи населения территориального органа [Росстат](https://rosstat.gov.ru).
- Датасет был очищен от системных ошибок ручного ввода данных управляющими компаниями. Нижняя граница фильтрации установлена на 1800 год для автоматического отсечения «цифрового мусора» и нулевых заглушек.
- Из финального анализа исключены нежилые здания и строки с нулевыми или пропущенными маркерами в графе жилых помещений (`living_quarters_count`).
- При структурировании и нормализации табличных данных использовался генеративный искусственный интеллект для оптимизации синтаксиса векторных масок в Pandas.

## Структура проекта

- `tver-jkh-transport` — рабочая папка проекта
    - `data/` — папка, содержащая исходный очищенный массив данных Реформы ЖКХ (`reforma_jkh_tver.csv`).
    - `output/` — результаты графического анализа в высоком разрешении (тренды домохозяйств `tver_household_dynamics.png` и структура высотности `tver_building_morphology.png`).
    - `requirements.txt` — файл внешних зависимостей для автоматического развертывания воспроизводимой среды выполнения.
    - `template-project-notebook.ipynb` — Jupyter Notebook с полным воспроизводимым циклом исследования: импорт библиотек, предобработка данных, векторная фильтрация логических условий, обратное демографическое моделирование и визуализация.

## Стек технологий

- Python 3.12 (Pandas, NumPy) — загрузка датасета, фильтрация, приведение типов текстовых колонок к числовым, вычисление измененных коэффициентов и группировка по морфологии этажности.
- Matplotlib — визуализация двухрисковых аналитических распределений и построение горизонтальных столбчатых диаграмм с кастомизированными цифровыми метками (без багов отображения).

## Вывод и подтверждение гипотезы

В ходе исследования метод обратного демографического моделирования подтвердил выдвинутую гипотезу. Были выведены локальные измененные размеры домохозяйств для г. Твери: **3.24 чел.** на одну квартиру в 2010 году и **2.92 чел.** в 2021 году. Данные коэффициенты существенно опережают базовый региональный норматив [Демоскоп Weekly](http://demoscope.ru) (2.4 чел.). Полученная аномалия математически доказала факт жесткого недоучета емкости жилой застройки в исходном массиве ведомства.

При детальном анализе структуры фонда по высотности («*Структурный состав квартирного фонда Твери...*») и аудите дефектных строк были локализованы ключевые драйверы искажения статистики:
1. **Исключение индивидуального жилого фонда (ИЖС):** База ЖКХ агрегирует данные преимущественно по многоквартирным домам, полностью исключая из знаменателя формулы обширные районы частного сектора Твери. Меньшее число квартир при полной численности населения по [Росстату](https://rosstat.gov.ru) искусственно завышает коэффициент.
2. **Институциональные пустоты ввода:** Около 15% строк в исходной базе содержали пропуски в графе квартир из-за халатности заполнения данных управляющими компаниями. Код отсек эти технические лакуны, что сократило расчетный знаменатель.
3. **Латентный демографический навес:** Динамика падения коэффициента с 3.24 до 2.92 отражает постепенное улучшение собираемости данных ведомствами к 2021 году, накладывающееся на процессы атомизации общества (строительный бум высотной застройки 6+ этажей, ориентированной на малогабаритные квартиры для одиночных домохозяйств).

Данное исследование помогло не только определить масштаб недоучета квартирного фонда, но и выйти на важные выводы для транспортного планирования. Использование «сырых» ведомственных данных без корректировки маскирует реальный пассажирский спрос целых районов. После ликвидации систем трамвая (2018 г.) и троллейбуса (2020 г.) данные недоучтенные демографические зоны Твери сформировали избыточное давление на автобусные маршруты и спровоцировали стихийную автомобилизацию, что будет подробно разобрано при написании курсового проекта.
