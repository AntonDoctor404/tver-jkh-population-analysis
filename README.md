## Превышение индикатора расчетного размера городских домохозяйств над региональными нормативами на основе ведомственных данных жилого фонда г. Твери

Статистико-географическое исследование, посвященное оценке реального демографического потенциала жилой застройки города Твери в межпереписной период, сопровождавшийся полной ликвидацией инфраструктуры городского электрического транспорта (ГЭТ).

## Объект исследования

Многоквартирный жилой фонд в административно-территориальных границах города Твери.

## Цель

Составить часть материала для демографического и инфраструктурного анализа для курсовой работы 2 курса. Доказать или опровергнуть предположение о наличии критических пустот в данных и дисбаланса в ведомственном учете жилых площадей, формирующих скрытые зоны пассажирского спроса.

## Гипотеза

Официальный ведомственный учет многоквартирного жилого фонда содержит системные пустоты и недоучитывает физический объем жилой площади города, из-за чего локальный расчетный размер домохозяйств математически завышается относительно реальных демографических трендов, маскируя очаги транспортной нагрузки.

## Уточнения

- При подготовке датасета использовалась официальная открытая выгрузка реестра домов Тверской области с государственного портала «Реформа ЖКХ»
- В качестве базового статистического ориентира использовались таблицы научного издания [Демоскоп Weekly](https://www.demoscope.ru/weekly/ssp/rus_hh_10.php) (средний размер частных домохозяйств в городских населенных пунктах региона равен 2.4 человека).
- Официальные демографические вехи численности населения г. Твери (403 606 жителей в 2010 г. и 416 219 жителей в 2021 г.) взяты из официальных бюллетеней и результатов Всероссийской переписи населения территориального органа [Росстат](https://rosstat.gov.ru).
- Датасет был очищен от системных ошибок ручного ввода данных управляющими компаниями. Нижняя граница фильтрации установлена на 1800 год для автоматического отсечения «цифрового мусора» и нулевых заглушек.
- Из финального анализа исключены нежилые здания и строки с нулевыми или пропущенными маркерами в графе жилых помещений (`living_quarters_count`).
- При структурировании и нормализации табличных данных использовался генеративный искусственный интеллект для оптимизации синтаксиса векторных масок в Pandas.

## Структура проекта

- `tver-jkh-transport` — рабочая папка проекта
    - `data/` — папка, содержащая исходный очищенный массив данных Реформы ЖКХ (`reforma_jkh_tver.csv`).
    - `output/` — результаты графического анализа в высоком разрешении (тренды домохозяйств `tver_household_dynamics.png` и структура высотности `tver_building_morphology.png`).
    - `requirements.txt` — файл внешних зависимостей для автоматического развертывания воспроизводимой среды выполнения.
    - `template-project-notebook.ipynb` — Jupyter Notebook с полным исследованием.

## Стек технологий

- Python 3.12 (Pandas, NumPy) — загрузка датасета, фильтрация, приведение типов текстовых колонок к числовым, вычисление измененных коэффициентов и группировка по морфологии этажности.
- Matplotlib — визуализация двухрисковых аналитических распределений и построение горизонтальных столбчатых диаграмм с кастомизированными цифровыми метками (без багов отображения).

## Вывод и подтверждение гипотезы

Проведенный расчет выявил явные структурные аномалии ведомственного учета: вычисленный локальный размер домохозяйства для Твери составил **3.24 чел.** в 2010 году и **2.92 чел.** в 2021 году. Это существенно выше нормативной базы [Демоскоп Weekly](https://www.demoscope.ru/weekly/ssp/rus_hh_10.php) (2.4 чел.). Это расхождение в данных подтверждает гипотезу о *критическом скрытом недоучете жилой площади* в таблицах ведомств при отсутствии ГИС-корректировки.

1. **Игнорирование частного сектора (ИЖС):** Реестр «Реформы ЖКХ» агрегирует информацию преимущественно по *многоквартирному фонду*. Огромные по площади территории индивидуальной жилой застройки Твери, зафиксированные на графике этажности минимальным объемом, физически выпали из знаменателя формулы. Меньше учтенных квартир при неизменном населении города по [Росстату](https://rosstat.gov.ru) автоматически приводят к завышению коэффициента.
2. **Технические пустоты заполнения:** Как показала данная работа, значительный процент домов Твери содержит нулевые маркеры квартир из-за несвоевременного заполнения базы управляющими компаниями. На этапе предобработки эти данные отсекаются, искусственно занижая реальную емкость жилья и коэффициент соответственно.
3. **Фактор новостроек и атомизации:** Наблюдаемый тренд падения коэффициента с 3.24 до 2.92 отражает постепенное улучшение учета домов ведомствами к 2021 году.

### Транспортные последствия для Твери:
Опираться на некорректированные ведомственные базы данных в транспортном проектировании опасно. Из-за скрытых данных в учете ЖКХ, целые районы частного сектора и недоучтенные жилые дома маскируют реальные очаги концентрации пассажиропотоков. После полной ликвидации трамвайной (2018 г.) и троллейбусной (2020 г.) систем Твери эти недоучтенные зоны формируют зоны перегрузки коммерческих автобусных маршрутов и провоцируют хаотичную автомобилизацию города.
